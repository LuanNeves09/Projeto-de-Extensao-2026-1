# Projeto Conecte: Implementação de Tecnologias Digitais e Metodologias Ativas na Educação

## Sobre o Projeto
O Projeto Conecte visa capacitar professores quanto ao uso de novas tecnologias para serem utilizadas em sala de aula. Tendo em mente que a metodologia atual de ensino segue, muitas das vezes, o mesmo método robotizado há anos, nós queremos mostrar ferramentas de design + IA + simulações para ajudar o dia a dia destes professores.

## Objetivos (SMART)
* **Objetivo Geral:** Capacitar no mínimo 15 professores da comunidade no uso de ferramentas digitais ativas (IA, Canva e Simulação) até o final da Sprint 5 (Semana 13).
* **IA:** Realizar 1 aula de pelo menos 2 horas sobre o uso ético e prático de Inteligências Artificiais até a Sprint 4.
* **Design:** Desenvolver 1 workshop prático sobre princípios de design no Canva até a Sprint 5.
* **Simulação:** Elaborar e entregar 1 guia prático com tutoriais de ferramentas de simulação virtual até a Sprint 5.
* **Feedback:** Coletar feedback qualitativo de pelo menos 80% dos professores capacitados até a Semana 15.
